# Manager portraits

Five transparent comic-style manager faces for Futbol Manager. Each portrait uses the same charcoal jacket, off-white shirt, neutral lighting, and head-and-shoulders framing.

| Asset | Inspiration |
| --- | --- |
| `manager-mourinho.png` | José Mourinho |
| `manager-klopp.png` | Jürgen Klopp |
| `manager-vieira.png` | Patrick Vieira |
| `manager-guardiola.png` | Pep Guardiola |
| `manager-southgate.png` | Gareth Southgate |

`manifest.json` contains stable IDs, relative image filenames, pixel dimensions, and accessible descriptions. Resolve each `file` relative to this directory. PNG files retain their original transparent alpha channel.

For avatar slots, use `object-fit: contain; object-position: center bottom` on a square image area. Apply any card background or circular mask in the UI rather than altering the source artwork.

These are AI-generated comic portraits inspired by the named managers, rather than official club graphics. Created with the built-in image-generation tool, with the first portrait used as the visual reference for the remaining four.
