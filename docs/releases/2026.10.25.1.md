# Release 2026.10.25.1

## Changes

- Load all 543 supplied Premier League first-team profiles by stable source ID, including fictional names, positions, ages and 26 attributes.
- Derive CA and PA from the documented calibration. The builder and live game share one versioned CA calculation; training, positional ratings, goalkeeper units and edits retain the player’s method. Existing progressed careers retain their development.
- Keep club real names in metadata; remove them from club selection, directory rows and profile headers.
- Estimate missing height/weight once and save the baseline. Recover legacy identities before supplemental additions and deduplicate by source ID and normalized inspiration.

## Validation

All 54 test suites passed on the final code. The strict engine audit passed 3,555 checks across 1,109 scenarios. Database generation matched all 543 players; CA mean 77.2, range 63–93.

Roster tests now account for supplemental identities and squads larger than the 25-player registration list. Profile tests recognize calibrated and expansion sources and reconstruct legacy names for legacy migration checks. The passing scenario now places the presser outside the passing lane; no match decision code or engine tuning was changed. Migration fixtures normalize identity spelling and isolate the identity being reconstructed.

## Limitations

Scoring is below the previous roughly 2.8 goals-per-match target, with more 0–0 draws. These runs establish completion and score distributions, not that league realism is fully calibrated. Supplied attributes and engine tuning were preserved; improving league scoring requires a separate football behavior review. The full revised roster applies to new careers and untouched starting saves; developed saves keep their existing attributes and CA/PA.
