# Transfers feature film

37 s, 1920x1080 HyperFrames film: a floating phone, giant hero words behind it and animated callouts, all built from real screenshots of the game.

- `assets/` real captures of one full deal (search, scout, offer, package, Director memo, agent fee, sign, squad), taken by driving the game in a headless phone-sized browser.
- `build.py` generates `index.html` (edit the callout and beat tables at the top, then run `python3 build.py`).
- `futbol-manager-transfers.mp4` the render (`npx hyperframes render -o futbol-manager-transfers.mp4`).
- No audio track yet.
